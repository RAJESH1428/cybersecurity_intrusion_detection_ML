# Cybersecurity Intrusion Detection using Machine Learning

## Overview

This project develops an end-to-end machine learning pipeline to classify network traffic as either **Normal** or **Attack**. The implementation compares supervised, unsupervised, and deep learning algorithms for cybersecurity intrusion detection.

## Dataset

- Records: 9,537
- Features: 11
- Target Variable: `attack_detected`

## Machine Learning Models

### Supervised Learning
- Random Forest Classifier
- Logistic Regression

### Unsupervised Learning
- Isolation Forest
- K-Means Clustering

### Deep Learning
- Multi-Layer Perceptron (MLP)
- Autoencoder

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix
- Silhouette Score
